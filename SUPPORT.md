# Getting help

- **A question, an idea, or "how do I"**: start a thread in
  [Discussions](https://github.com/BijectiveLabs/trading-research-agents/discussions). Others
  will have the same question, and the answer stays findable.
- **Something is broken**: open an issue with the Bug form. The form asks for `tra --version`,
  the command and its output; `--plain` output pastes cleanly and never contains a key.
- **A security problem**: report it privately from the Security tab. See
  [SECURITY.md](SECURITY.md).
- **The documentation**: [docs.bijectivelabs.dev](https://docs.bijectivelabs.dev).

Issues are read by the maintainers, usually within a week. One with no activity for 30 days is
marked stale and closes 14 days later unless someone replies; reopening with new details is always
welcome. Dependency updates arrive from Dependabot once a month and merge on their own when the checks
pass.

This project is offered as is, under the MIT license. It is not investment advice, and nobody here
can tell you whether a strategy will make money.
